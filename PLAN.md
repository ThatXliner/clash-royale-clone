# Pre-Evolutions Card Battler Plan

The comparison target is `./reference`; it is test-only and must never be
imported, copied, or bundled into a shipped artifact. Runtime content uses
original names, art, text, and audio. Benchmark names may appear only in
test-only fixtures and reports.

## States

- `PENDING`: not built.
- `BUILDING`: a builder round is active.
- `FAIL`: a critic ran the artifact and named a concrete gap.
- `PASS`: a critic ran the acceptance command and found no gap on the
  dimension owned by the piece.
- `QUESTION`: three rounds found the same gap, or the reference value is
  low-confidence and needs calibration.
- `BLOCKED`: an explicit dependency is not `PASS`.

Every simulation piece must prove replay determinism: identical inputs and
seed produce byte-identical output. Time is integer ticks; randomness is
seeded and serialized. Reference JSON may be read by tests and offline
comparison scripts only.

Passing the isolated mechanics below does **not** establish a functioning
game. Product completion additionally requires every `GAME-*` executable
journey to pass in the shipped browser entry. The current scoped roster is playable against AI, but those journeys alone
do not establish complete historical card execution or a finished release.

## First public release scope

The October 4 request targets the full 109-card pre-Evolutions battle roster
against AI, with an original shipped identity for each role, editable decks,
card information, and a deterministic JS/RL API. Publish the verified browser
game on GitHub Pages. Accounts, ranked progression, clans and online play are
outside this first release, as confirmed by the user. Isolated catalogue or
encounter tests do not count as playable roster coverage. Completion inventory:
`docs/completion-inventory.md`. All release claims must preserve reference
confidence limits.
