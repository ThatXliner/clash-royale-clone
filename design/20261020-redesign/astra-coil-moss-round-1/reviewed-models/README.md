# Native model review sources

These are the exact editable Blender authoring files and GLB exports inspected in the independent native-art reviews. They are design sources, not runtime assets. The accepted Mossguard model is in native-round-1; both Coilblade versions failed the saber identity/readability bar. Retain those failures as comparison evidence.

provenance.json maps these bounded copies to the original capture paths and hashes. The full local render attempts and tool-repair snapshots remain preserved separately; this package does not claim a hermetic regeneration pipeline. Native evidence and reports are in artifacts/astra-native-model-reviews/. No reference assets are included.
