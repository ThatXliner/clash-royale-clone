# Skymaul

An original floating golem for Moss & Ember. Claude directed the character design; Astra built the model. Original source and assets are licensed AGPL-3.0-only.

[Editable model, source and reproduction commands](bundle/README.md) · [Battle sprite atlas](atlas/skymaul-battle-sprite.png) · [Independent review](../../artifacts/app-redesign-atlas-003/critic/VERDICT.md)

The saved model, portrait and 24-cell atlas passed independent review. The portable bundle reproduces the renders without access to the authors’ working folders. Live battle integration and animation are still pending.

The atlas uses 64×64 cells: east, north, south and west across; River idle/walk/contact followed by Ember idle/walk/contact down. The ground pivot is (32,54). See the bundle for exact input hashes, original geometry source and Blender verification commands.
