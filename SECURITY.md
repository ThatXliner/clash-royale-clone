# Security policy

Please report security issues privately. Check the repository's **Security**
tab for GitHub's **Report a vulnerability** option and use it if available.
This repository has not confirmed that private vulnerability reporting is
enabled, so do not assume that a public issue is a private channel.

If the private reporting option is unavailable, open a minimal public issue
asking maintainers for a private reporting route. Do not include exploit
steps, credentials, private data, or other sensitive details in that issue.
