31-## Corroboration flags
32-
33:`cards.json` is intentionally conservative. For every card, `unverified_fields` names each non-null mechanic value that was not corroborated against a second historical source at the same cutoff. A missing name in that array means either:
34-
35-1. it is an identity/schema field directly confirmed by the roster and card overview; or
36-2. it is one of the hardcoded independent spot checks in `validate.py`.
37-
38:This prevents a structured datamine from being mistaken for two-source verification. Null values are “not applicable/not safely expressible,” not unverified numeric claims. Tower and arena files use the same convention.
