# Cinderback → Firecracker: bounded raw-source audit

## Finding

The existing recoil test is a positive test-only identity join: `tests/special-movement-recoil.test.js` calls the comparator with key `firecracker`, then requires no authoritative field failures. That explicit comparator selected this audit’s rows. No branding-name comparison or numeric-ID equality was used to establish the join. This packet does not change the binding, admit Firecracker, or claim historical recoil execution.

The pinned rows close a source chain from the Firecracker character’s `projectile="FirecrackerProjectile"` to that projectile’s `spawn_projectile="FirecrackerExplosion"`. Both named rows match exactly once and are saved in full, together with their identical combined-table duplicates. The normalized reference’s `damage: null` therefore cannot be read as proof that the source has no projectile. The source chain does not, by itself, define how the game applies the linked rows.

The local audit baseline is accepted commit `226c55248d5c3a6f77e87ef40bb9eb0f32cd5ebf`. The 2023-02-18 snapshot is RoyaleAPI `cr-api-data` commit [`54fdef52c5086393b085f57faeeab8ef86b28160`](https://github.com/RoyaleAPI/cr-api-data/commit/54fdef52c5086393b085f57faeeab8ef86b28160). Six pinned JSON files were fetched in memory. HTTP status, final URL, direct exit code, byte count, SHA-256, Git blob SHA-1, and source row counts are in [`SOURCE-LEDGER.tsv`](SOURCE-LEDGER.tsv) and [`source-receipts.json`](source-receipts.json). No whole upstream table or asset was written. The selected output contains 10 complete ordered rows and 925 raw field positions; [`field-consumer-disposition.tsv`](field-consumer-disposition.tsv) gives each field’s ordinal, exact JSON value, confidence/Q label, and bounded disposition.

## Joins and retained values

The explicit comparator selects roster `key=firecracker` (one row). Its `Common` rarity row is unique and has `tournament_level_index=10`, the Common level-11 array position. A visible troop row joins by key, English name, rarity, and `not_visible=false`; its `summon_character="Firecracker"` joins to the selected character row. The troop, character, and both projectile rows compare byte-for-value equal to their respective rows in combined `cards_stats.json`.

The selected character stores `hit_speed=3000` and `load_time=2400` in raw source units, plus `deploy_time=1000`, `range=6000`, `sight_range=8500`, and `speed=90`. Its level-11 HP array entry is index 10 = 304; `damage_per_level` is null. These raw values remain separate. The local normalized record marks HP, timing, deploy, ranges, speed, target mode, and count as unverified. The 2.4-second `load_time` normalization and the existing Cinderback 144-tick first-hit fixture remain QUESTION-backed.

The character’s direct projectile reference is unique. `FirecrackerProjectile` retains raw `speed=400`, null `damage_per_level`, and `spawn_projectile="FirecrackerExplosion"`. The second row retains raw `speed=550`, `damage=25`, `radius=400`, `projectile_radius=400`, `projectile_start_extra_radius=650`, `projectile_range=5000`, `spawn_count=5`, `spawn_radius=80`, `constant_height=1000`, and `damage_per_level[10]=64`. Values, flags, ordering, and unknown unit semantics remain in the full rows. `spawn_count=5` is not normalized to pellet count or a hit rule. A Firecracker self-name in `summon_character` is recorded as a row relation; it does not prove spawn behavior. Zero, false, and null fields do not establish that a mechanic is absent.

The normalized card’s `damage` and `area_damage_radius_tiles` are null, while the linked projectile rows contain raw damage and radius fields. Those are preserved side by side in [`normalized-comparison.tsv`](normalized-comparison.tsv); the source table alone does not resolve damage composition, radius conversion, or contact behavior. The official January 2020 note supplied by the root qualitatively mentions an impact firework and sparks behind the target. It does not validate the raw `spawn_count`, hit distribution, or recoil units.

The comparator table now contains exactly the 14 mappings in `test_only_binding.comparator_fields`, joined to the one-element return receipt from the actual `createRecoilSpecialCatalog()` call in [`current-catalog-profile-receipts.json`](current-catalog-profile-receipts.json). The full normalized Firecracker projection is separated into [`firecracker-normalized-context.tsv`](firecracker-normalized-context.tsv), where reference rows are clearly labeled as context rather than Cinderback comparator rows. If “40% faster” means a delay became 60% of its prior value, a 0.4-second absolute reduction implies approximately 1.0 seconds to 0.6 seconds; that is conditional arithmetic, not a mapping to `load_time` or `hit_speed`. Direct old/new raw evidence and the consumer phase remain open. See [`official-source-notes.md`](official-source-notes.md); the root retains its separate primary-source artifact.
