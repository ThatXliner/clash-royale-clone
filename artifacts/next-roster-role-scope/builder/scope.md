## Candidate and why it is actionable

The current mixed editable collection has 20 IDs and contains only one structure, Ember Basin (`src/content/editable-deck.js:17-21`; verified by importing the exported list). Buried Coil is already a distinct original identity in the shared card manifest and is admitted as a defensive structure, but it is not in that 20-ID list. Its existing profile is a single-target hidden defensive building, while Ember Basin is a splash building; this gives the collection a genuinely different defensive role without requiring a new simulator or a second building engine.

This path is already exercised through the real `GameSession`. `tests/game-roster-buildings.test.js:208-243` creates and deploys each admitted building, then checks the shared structure materialization, once-only elixir spend and deck cycle. Its setup helper constructs a `GameSession` (`:80-103`). The defensive QUESTION scenario at `:258-282` deploys Buried Coil against a Mossguard, observes the attack at tick 102 for 230 damage, and checks the reveal event. This is shared-session behavior, not a catalog-only count. It proves a ground-target path; a new editable-choice qualification still needs actual player and seeded-AI selection, plus an air-target check before describing both target layers as exercised.

The minimum collection integration is the mixed editable allowlist in `src/content/editable-deck.js:17-21`. The existing witness and setup code already projects allowed non-units through `projectSessionNonUnitBattleCard` (`:70-100`, `:115-152`), and the card catalog attaches the admitted defensive profile (`src/content/session-card-catalog.js:93-110`, `:250-282`). RL setup takes its deck from that same editable API (`src/rl/environment.js:93-104`); its structure observations are built from the mixed allowlist (`:24-28`, `:134-160`). The app-shell and arena-shell also enumerate this allowlist (`src/ui/app-shell.js:11-13,338-362`; `src/ui/arena-shell-entry.js:74`). No shared-mechanics expansion is indicated by this source inspection.

The current product name is **Buried Coil** (`src/content/cards/buildings-defensive.js:81-87`). A targeted source search found only its defensive profile and session-card catalog registration. Neither the public asset filenames nor `src/ui/card-lore.js`, `src/ui/app-shell.js`, or `src/ui/arena-shell-entry.js` contains a matching Buried Coil/Tesla presentation entry; there is no matching public portrait, battle sprite, or lore entry. Making it a visible choice therefore needs original presentation art and original lore, in addition to editable-choice UI/AI/RL integration. The search does not authorize copying the comparison card's name, text, or art; the comparison name below is for source analysis only.
